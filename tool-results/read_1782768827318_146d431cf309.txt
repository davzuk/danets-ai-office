     3→## Project Overview
     4→**Danets AI Automation** — a multi-tenant SaaS platform (by Danets TecPro Limited) for AI-powered website chat, lead capture, and quote/proposal generation.
     5→
     6→Original brief requested Laravel; adapted to the available sandbox stack: **Next.js 16 (App Router) + TypeScript + Prisma (SQLite) + shadcn/ui + z-ai-web-dev-sdk**.
     7→
     8→## Architecture & Conventions (IMPORTANT — read before coding)
     9→
    10→### Stack
    11→- Next.js 16 App Router, TypeScript 5, Tailwind CSS 4, shadcn/ui (New York).
    12→- Prisma + SQLite. Client: `import { db } from "@/lib/db"`.
    13→- AI: `z-ai-web-dev-sdk` — **backend only**. Use `import { aiChat, logUsage, retrieveKnowledge } from "@/lib/ai"`.
    14→- Auth: custom DB-backed sessions (httpOnly cookie `danets_session`).
    15→  - `import { getSession, requireSession, createSession, destroySession } from "@/lib/auth"`.
    16→  - `requireSession()` throws `"UNAUTHORIZED"` if no session; returns `SessionUser` `{ userId, businessId, name, email, role, businessName }`.
    17→- API helper: `import { apiHandler, withSession } from "@/lib/api"`.
    18→  - `withSession((user) => ...)` wraps a handler, auto-returns 401 if not authed.
    19→- Rate limiting: `import { rateLimit, getClientIp } from "@/lib/rate-limit"`. `rateLimit(key, limit, windowMs)` returns `{ success, remaining, resetAt }`.
    20→
    21→### Multi-tenancy / Security
    22→- **Every** authenticated query MUST filter by `user.businessId`. Never trust a client-supplied businessId.
    23→- Public endpoints (widget chat) identify the business via `publicKey` (NOT internal id).
    24→- All AI calls server-side. Keys never exposed to client.
    25→
    26→### Database schema (prisma/schema.prisma) — 12 models
    27→`Business`, `BusinessUser`, `Session`, `AiAgent`, `KnowledgeBaseItem`, `ChatSession`, `ChatMessage`, `Lead`, `AiPromptTemplate`, `AiUsageLog`, `QuoteRequest`, `GeneratedDocument`, `SubscriptionPlan`.
    28→
    29→### Frontend structure
    30→- Single user route `/` (src/app/page.tsx) — SPA with client-side view switching.
    31→- Dashboard shell: `src/components/dashboard/app-shell.tsx` (sidebar + topbar + footer). `ViewId` type lists all views.
    32→- Views live in `src/components/dashboard/views/<name>-view.tsx`. Each receives `user` prop: `{ userId, businessId, name, email, role, businessName }`.
    33→- Brand: blue primary (`bg-primary`), lemon green accent (`bg-accent`). `.brand-gradient` / `.brand-text` utilities available. Sidebar is dark by default.
    34→
    35→### API routes layout
    36→`src/app/api/<resource>/route.ts`. Authenticated routes use `withSession`. Public routes under `src/app/api/public/`.
    37→
    38→### Seeded demo
    39→- Login: `admin@danetstecpro.com` / `danets123`
    40→- Business publicKey: see DB (printed by seed). Embed code uses `/widget.js?pk=<publicKey>`.
    41→
    42→### Skills
    43→- LLM skill loaded. Pattern: `const zai = await ZAI.create(); const c = await zai.chat.completions.create({ messages, thinking:{type:'disabled'} })`. Wrapped in `src/lib/ai.ts` → `aiChat(messages)`.

If AI generation fails the quote is still saved as `draft` and the API throws a clear message — the user can retry via `/api/quotes/generate`.
   227→- `src/app/api/quotes/[id]/route.ts` — `GET` returns the single quote + all its `GeneratedDocument`s (ordered `createdAt desc`); `DELETE` removes the quote (and its `GeneratedDocument`s first, since the schema uses `onDelete: SetNull` which would otherwise orphan them). Both handlers verify ownership with `findFirst({ where: { id, businessId: user.businessId } })` and throw `"FORBIDDEN"` if the quote is missing or belongs to another business (no existence leak). Uses async `params: Promise<{ id: string }>` per Next.js 16 convention. Both wrapped in `withSession`.
   228→- `src/app/api/quotes/generate/route.ts` — `POST` body `{ quoteRequestId }` (zod-validated). Loads the `QuoteRequest` (verifies `businessId` ownership → throws `"FORBIDDEN"` otherwise). Builds a brief string from all stored fields (clientName, companyName, service, requirements, budgetRange, timeline, notes). Calls `aiChat([{role:"system",...},{role:"user",...}])` instructing the model to output exactly 7 sections (`## Project Summary`, `## Scope of Work`, `## Deliverables`, `## Timeline`, `## Pricing Guidance`, `## Terms and Conditions`, `## Next Steps`) with placeholder price ranges and placeholder terms. Saves a new `GeneratedDocument` (`type:"proposal"`, `title:"Proposal - <clientName>"`), calls `logUsage(user.businessId, "quote", tokens)`, updates `quoteRequest.status = "generated"`.
